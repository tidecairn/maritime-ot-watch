PRIVACY

The public Watch does not ask for facility inventory.

This site is intentionally static and minimally instrumented.

What Tidecairn code collects

No accounts, analytics SDKs, advertising SDKs, cookies, file uploads, inventory submissions, or remote readiness-check forms are implemented in this release. The evidence-readiness self-check executes in the browser.

Hosting-layer logs

The hosting provider may retain ordinary request/security logs such as IP address and user agent under its own policies. GitHub states that GitHub Pages records visitor IP addresses for security purposes. Tidecairn does not add a separate analytics layer in this release.

External sources

Opening a primary-source link navigates to the relevant agency or vendor website, whose own privacy practices then apply. The Watch uses a no-referrer policy so the browser does not intentionally send the Watch page URL as a referrer.
